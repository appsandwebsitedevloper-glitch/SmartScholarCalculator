# SmartScholar Calculator

A single-page scholarship preparation calculator built with plain HTML, CSS, and JavaScript.

## Structure

- `index.html` - application shell and screen markup
- `css/main.css` - global styles, components, responsive rules, and animations
- `js/app.js` - application data, routing, feature logic, and initialization

## Run

Open `index.html` in a modern browser. The app uses hash-based navigation and browser local storage for saved data.

The only external dependency is the Outfit font loaded from Google Fonts.
